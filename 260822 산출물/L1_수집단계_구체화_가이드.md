# L1 수집 단계 구체화 가이드

> 데일리 파이프라인 **1단계(뉴스 수집)** 확장 설계 · 구현용
> 기준 자료: `docs/데일리_파이프라인.md`(현행 1단계) · `docs/수집규칙.md`(필수 수집) · 「마켓센싱 정보수집 계층 통합.xlsx」(소스 마스터)
> 상태: **v0.3** — 소스별 수집방식 검증 + 월별 수집 스케줄 캘린더 반영(2026-08). [확인필요]/[보류]는 후속 확정 대상.

---

## 0. 목적

현행 수집(1단계)은 **키워드 웹검색 기반**이라 새 이슈 포착에 강하나, **정기 발간보고서·기술전시회·트렌드 뉴스레터 등 "정해진 소스"를 주기에 맞춰 확보하는 경로가 없다**(필수 수집은 한국은행 BSI·ESI 2건뿐). 이 가이드는 그 공백을 메워 수집을 **① 이벤트 경로(현행)** 와 **② 소스·캘린더 경로(신설)** 두 축으로 구체화한다.

---

## 1. 현행 진단 (검증 결과)

| 항목 | 현행 | 판정 | 보완 방향 |
|---|---|---|---|
| 수집 방식 | 키워드 7그룹 **일반 웹검색** | 뉴스·이슈 포착에 강함 | 유지(경로 A) + 빅카인즈로 안정화 |
| 소스 명시성 | "무엇을 검색"은 있으나 "어느 발간물·사이트를 언제" 없음 | 갭 | 소스 마스터로 명시(경로 B) |
| 필수 수집 | BSI·ESI 2건만 캘린더 강제 | 갭 | 정기 발간물·전시회로 캘린더 확장(§4) |
| 분류 체계 | 10대 분류(**주제**) | 정상 | **유지** — 소스축과 병존 |
| 소스 유형 축 | 없음 | 갭 | 5 기본축(**소스**) 신설(§3) |

### 검증 포인트 — 분류(주제)와 소스축(출처)은 "직교"다
- **10대 분류** = 기사의 *주제*(업계/자사/경쟁사/글로벌/기술/사회/법령/경제/지표/M&A)
- **5 기본축** = 기사의 *출처 유형*(공공·정책/미디어·뉴스/연구·전문보고서/국내외 기술전/트렌드 뉴스레터)
- 한 기사는 **둘 다** 갖는다. 예: "KDI 9월 경제동향 발표" → 분류 `8. 경제 동향` + 소스축 `❸ 연구·전문보고서`.
- 소스축은 10대 분류를 **대체하지 않고 병기**한다(스키마에 `axis` 필드 신설 — §7).

### 빅카인즈에 대한 확인
- 현행 키워드 수집은 **Claude 일반 웹검색**으로 수행(빅카인즈 아님). 빅카인즈는 기존 개발에 없음.
- **빅카인즈(BIGKinds) OpenAPI**(한국언론진흥재단)로 보강 시, 언론사·기간·키워드 기준 **정형·재현 가능** 수집이 되어 웹검색의 범위·중복·재현성 편차를 줄인다. 단 가입 필요·주요 일간지/경제지 중심이라 **보안 전문지는 별도(보안뉴스 RSS) 병행**.

## 2. 수집 모델 — 두 경로 병행

```
경로 A · 이벤트/뉴스 (현행 유지 + 보강)
  키워드 7그룹 (일반 웹검색) + 빅카인즈 API → 신규 이슈·기사
경로 B · 소스/캘린더 (신설)
  소스 마스터의 정해진 소스를 발행 주기에 확보
     · 정기 발간보고서(월/분기/반기)  · 기술전시회(시즌)  · 트렌드 뉴스레터(월/수시)  · 지표(월)
                          │
                 ▼ 동일 스키마로 합류 ▼
        중복 제거(URL 기준) → 2단계 스코어링으로 전달
```

- 경로 A·B는 **출력 스키마가 같아야** 합류·중복제거가 된다(§7).
- 경로 B의 정기 발간물은 **캘린더 트리거**로, 발행월이 도래한 것만 수집한다(§4).

## 3. 소스별 수집방식 (1차 검증 반영)

> ✅ = 공개 API/RSS 확인(자동화 1순위) · 🔶 = 크롤(2순위) · 🔒 = 유료/회원/사내(후순위·수동) · ⏸ = 방식 보류

### 자동화 1순위 — API/RSS 확인됨
| 소스 | 축 | 방식 | 근거 |
|---|---|---|---|
| KOSIS·통계청 | ❶ | ✅ **공유서비스 OpenAPI** | kosis.kr/openapi |
| 국가법령정보센터(법령·입법) | ❶ | ✅ **공동활용 OpenAPI** | open.law.go.kr |
| 정책브리핑(korea.kr) | ❶ | ✅ **RSS** | korea.kr/etc/rss.do |
| 보안뉴스(+시큐리티월드 동일 발행) | ❷ | ✅ **RSS** | boannews.com/custom/news_rss.asp |
| 네이버 데이터랩(검색어 트렌드) | ❺ | ✅ **OpenAPI** | developers.naver.com |
| 일반 언론·포털(신문스크랩 보강) | ❷ | ✅ **빅카인즈 OpenAPI** | bigkinds.or.kr/v4/openApi |

### 자동화 2순위 — 크롤/다운로드
| 소스 | 축 | 방식 |
|---|---|---|
| 정부24·소상공인시장진흥공단·중소기업연구원·협동조합·이렇게달라집니다 | ❶ | 크롤(공개) |
| 국민참여입법센터·정부입법지원센터(입법예고) | ❶ | 크롤 / 법령 API 일부 커버 |
| 경찰청·대검·소방청/행안부·고용노동부(통계) | ❶ | 발간 통계 다운로드(+KOSIS 일부) |
| 세이프타임즈 | ❷ | RSS 추정(확인 예정) |
| 경제·금융 연구(KDI·한국은행·산업연구원) | ❸ | **캘린더 크롤 + PDF 다운로드** |
| 기술·R&D(SPRi·ITFIND·KISDI) | ❸ | 캘린더 크롤 + 다운로드 |
| 위협 인텔(안랩 ASEC·SK쉴더스 EQST·KISA) | ❸ | 리포트 페이지 크롤 |
| 기술전시회(CES·MWC·ISC WEST·IFA) | ❹ | **경로 A(뉴스) + 개최월 캘린더**, 공식 사이트 보조 |
| 나스미디어·CJ메조·SK스퀘어데이터랩·더외식 | ❺ | 공개 블로그 크롤 / 뉴스레터 수신 |

### 후순위 — 유료/회원/사내(수동 또는 보류)
| 소스 | 축 | 사유 |
|---|---|---|
| KISIA·KSIA·SIA 연차보고서 | ❸ | 연 1회·일부 회원제 → 발행기 수동 확보 |
| 엠브레인 트렌드모니터·캐릿(Careet) | ❺ | 유료/로그인 |
| 커뮤니케이션팀 신문스크랩(사내) | ❷ | 유지하되 **수집 방식 ⏸ 보류** — 사내 접근정책 확정 후 결정 |

> ⚠️ 후순위 원칙(합의): **회원제/유료·사내한정은 뒤로**, **무료·공개 우선**. 정기 발간물은 **발행월이 도래한 것만** 수집.

## 5. 분류 정합 (10대 분류 ↔ 5 기본축, 병기)

- 원칙: **분류(주제)는 현행 그대로**, **소스축(출처)만 추가 태깅**.
- 소스축 자동 판정 규칙(수집기): 발행처가 정부·공공·통계 → `❶`; 언론·포털·전문지 → `❷`; 연구원·협회 보고서 → `❸`; CES/MWC/ISC WEST/IFA → `❹`; 광고사·리서치 뉴스레터 → `❺`.
- 경로 B 수집분은 소스 마스터에 축·category가 이미 있으므로 그대로 승계.

## 6. 수집 방식별 구현 지침

| 방식 | 구현 힌트 | 사람 개입 |
|---|---|---|
| 키워드 웹검색(경로 A) | 현행 유지 — 7그룹, 전일~실행시각 | 없음 |
| 빅카인즈 API | 가입·키 발급 → 키워드·기간 조회, 언론 정형 수집 | 없음 |
| RSS/피드 | 정책브리핑·보안뉴스·입법예고 등. 신규 항목만 | 선별 |
| 공공데이터/공개 API | KOSIS·법령센터·네이버데이터랩. 지표·법령 정형 | 없음 |
| 크롤링 | 목록/기사 파싱, robots·약관 확인, 재시도·로그 | 선별 |
| 캘린더 크롤+PDF 다운로드 | 연구원 발간물 목록을 발행월에 확인 → PDF → 수치·표 추출 | **수치 검증(큼)** |
| 이메일 뉴스레터 | 공용 수신함 구독 → 파싱 | 주제 선별 |
| 유료구독/수동 | 담당자 확보 후 등록(반자동) | 확보·입력 |

> 착수 순서(쉬운 것 먼저): **RSS/공개 API → 빅카인즈 → 크롤 → 캘린더 발간물 → 뉴스레터/수동**

## 7. 출력 스키마 (수집 원자료 → 2단계 스코어링 입력)

경로 A·B 공통. 현행 필드 + **신규 필드(굵게)**. 기존 스코어링·태그·4관점 로직은 파괴 없이 필드만 추가.

```json
{
  "dt": "2026-08-21",
  "title": "…",
  "summary": "…",
  "source": "한국개발연구원(KDI)",
  "url": "https://…",
  "category": "8. 경제 동향",        // 10대 분류(주제) — 현행
  "track": "경제",                    // 현행
  "axis": "❸ 연구·전문보고서",        // ★신규: 5 기본축(소스 유형)
  "source_id": "REP-KDI-경제동향",    // ★신규: 소스 마스터 식별자
  "collect_path": "B",               // ★신규: A(이벤트)/B(캘린더)
  "collect_method": "캘린더 크롤+PDF", // ★신규: 수집방식
  "is_required": true                 // ★신규: 필수 캘린더 여부(스코어링 면제 판정 입력)
}
```

## 8. 구현 우선순위

1. **소스 마스터 데이터화** — 「소스별 수집방식(초안)」 시트 → `sources.json`(축·소스ID·방식·주기·URL·category). *선행 필수.*
2. **스키마 확장** — 수집 산출물에 `axis/source_id/collect_path/collect_method/is_required` 추가(하위호환).
3. **1순위 자동화 연결** — KOSIS·법령센터·정책브리핑·보안뉴스·네이버데이터랩(공개 API/RSS) + 빅카인즈.
4. **필수 캘린더(경로 B)** — §4 ★ 대상부터(BSI·ESI·KDI월간·SPRi월간·보안시장전망2월·정보보호실태조사9월).
5. **크롤/발간물 순차 확장** → 이후 뉴스레터·수동.
