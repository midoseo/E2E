# ④ 판단 에이전트 — 관점 종합 규칙 (v1)

> 관점 에이전트(③) 3개의 출력을 하나의 최종 판정으로 모으는 규칙.
> "손으로 판정" → "규칙으로 산출"로 전환. 대시보드 `synthesize()`로 구현됨(참고: index.html).

## 입력
관점별로 = { axis(사업기획/상품기획/마케팅), decision, confidence, judgment, boundary }
- decision은 카테고리로 정규화:
  - **support(게재 지지)**: 게재 / 채택 / 신사업 검토
  - **conditional(조건부)**: "조건부 게재"
  - **noise(노이즈)**: 미게재 / 기각
  - **hold(보류)**: 보류
- confidence(간이): "신사업"·noise → 높음, 그 외 → 중간. (추후 관점 에이전트가 직접 출력)

## 최종 판정 규칙
1. support ≥ 1 → **게재**
2. support 0 & conditional ≥ 1 → **조건부 게재** (경계조건을 트리거로 명시)
3. support 0 & noise ≥ 1 → **미게재** (노이즈 필터)
4. 그 외 → **보류**

> 설계 사상: 마켓센싱은 **놓치는 비용 > 노이즈 싣는 비용**. 한 관점이라도 기회/위협으로 강하게 잡으면 싣는다. 대신 노이즈는 3번에서 확실히 거른다.

## 우선순위 규칙
- 미게재/보류 → **낮음**
- support ≥ 2 (관점 수렴) → **높음**
- support 1개라도 confidence 높음(신사업·중대 위협) → **높음**
- 그 외(단일 support 중간, 조건부) → **중간**

## 관점 충돌 처리 (핵심)
- 정의: support ≥ 1 **그리고** noise ≥ 1 (관점 간 결론이 반대).
- 처리:
  1. **충돌을 지우지 않는다** — 그 자체가 인사이트.
  2. 게재 여부는 **기회/위협 관점 우선**(놓침 비용). → 게재.
  3. 반대(노이즈) 관점을 **리포트에 '이견'으로 병기**.
  4. UI에 「관점 충돌」 배지 표시.
- 예: 한화비전 광고 — 상품기획(공급망 리스크·게재) vs 마케팅(일회성 광고·노이즈) → 게재 + "(이견: 마케팅 — 노이즈)".

## 리포트 반영 문장
- 게재/조건부: 최상위(확신도 높은) 관점의 judgment를 헤드라인으로.
- 충돌 시: 뒤에 "(이견: <관점> — 노이즈 판단)" 병기.
- 미게재: 리포트 제외(빈 문자열).

## 확신도 종합
- 관점 수렴(support≥2) → 상향
- 단일·경계조건 많음 → 중간
- 충돌 미해소 → 하향(이견 병기로 관리)

## 한계 / 다음 단계
- 현재 confidence는 decision 텍스트로 간이 추론 → 관점 에이전트가 **confidence를 직접 출력**하도록 개선 필요.
- 영향도(impact) 축이 없음 → "시장 규모·당사 매출 영향" 가중을 우선순위에 추가 검토.
- 충돌의 '강도'(약한 이견 vs 정면 대립) 구분 없음 → confidence 차를 반영해 고도화 가능.
